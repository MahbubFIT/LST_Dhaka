# Contributing Guidelines

Thank you for your interest in contributing to this project.
This repository supports the Master’s thesis:
“Urban Heat Vulnerability in Dhaka (2014–2024)” by Mahbubul Alam.

## How You Can Contribute

### 1. Reporting Issues
If you find a bug, unclear documentation, or unexpected behaviour:
- Open an issue with a clear title
- Describe the problem and steps to reproduce it
- Include screenshots or logs if helpful

### 2. Improving Code
Pull requests are welcome for:
- Code clarity and readability
- Performance improvements
- Additional comments or documentation
- Minor bug fixes

### 3. Adding Notebooks or Visualizations
You may contribute:
- Alternative visualizations
- Exploratory notebooks
- Additional analysis that builds on the existing workflow

### 4. Style Guidelines
- Use clear, descriptive variable names
- Keep scripts modular and readable
- Add comments for major processing steps
- Avoid hard‑coded file paths when possible

### 5. Data
This project uses:
- Google Earth Engine assets
- CSV tables stored in Google Drive
- Public Landsat data

Please do not upload raw data to the repository.
